> *"Millager——militia（民兵）与 villager（村民）的合成词——指的是守卫在村庄与灾厄威胁之间的武装村民们。"*

**Millager** 为村民阵营深度打造了一支正规军——有步兵、有骑兵、有傀儡师和傀儡们。它们编队巡游于山林、救受袭村庄于灾厄，受遣于遍布世界各地的小小指挥所。如果你希望打一场有友军援助的袭击，这个模组或许就是你想要的。
